# Employee Management System - Core PHP & MySQL

## About the Project

A practical Employee Management System built using Core PHP and MySQL.
This project demonstrates backend development fundamentals and database
operations.

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- PDO
- Linux (Ubuntu / WSL)
- Git and GitHub

## Features

- Add employees
- Display employee records
- Edit employee details
- Update employee information
- Delete employee records
- Search employees
- Show all employees

## Database

Database: laravel_practice

Table: employees

Fields:
- id
- name
- salary

## Setup Instructions

1. Install PHP, MySQL and Apache.
2. Create a database named laravel_practice.
3. Create the employees table.
4. Copy db_connect.example.php to db_connect.php.
5. Enter your own database credentials.
6. Run the application using your local PHP server.

## Learning Objectives

- PHP and MySQL integration
- PDO database connections
- CRUD operations
- SQL queries
- HTML forms
- Backend application development
- Linux terminal and Git workflow
